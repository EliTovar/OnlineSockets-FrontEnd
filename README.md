
# Multiplayer Scene

This is a little project using JS to control a character and walk in a scenario, adicionaly you can talk with people and use others funcions to play and testing objects and basic physics.





## Installation

Install my-project with npm

```bash
  npm install
  npm run dev
```
    
## What I use?

 - [Socket.io](https://socket.io/)
 - [ThreeJS](https://threejs.org/)
 - [CannonJS](https://schteppe.github.io/cannon.js/)
 - [SCSS](https://sass-lang.com/)
 - [Tailwind](https://tailwindcss.com/)
 - [DaisyUI](https://daisyui.com/)

I used socket.io to connect multiple users in a scene and talk to each other.
